# Batch Scaler

A cocktail batch calculator. Enter how many drinks you are making and the recipe, and it shows how much of each ingredient you need, how many bottles to buy, and what it costs.

**Open it:** https://dimamadalin11-cmyk.github.io/batch-scaler-for-bartenders/

## What it does
- Scales any recipe to any number of drinks (amounts in ml)
- Rounds up to whole bottles
- Shows total volume, total cost and cost per drink (prices in RON)
- Saves recipes in your browser
- Backup: Export copies your recipes as text, Import restores them

## Notes
- Recipes are stored only in the browser you save them in. Use Export to move them to another device.
- It is a single file (`index.html`) with no server and no installs.
